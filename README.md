# SmartIntern

> An AI-powered academia-industry collaboration platform designed for automated resume parsing, skill-gap analysis, and internship matching. Developed for Innovative Design Lab – I.

## 🚀 Live Prototype
Check out the live working prototype deployed on GitHub Pages:
[https://preethiCodes31.github.io/smart-intern/](https://preethiCodes31.github.io/smart-intern/)

## 🛠️ Tech Stack
* **Frontend:** React.js, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL
* **NLP Matching Engine:** Python / JavaScript TF-IDF & Cosine Similarity

---

## 📂 Repository Structure
* `/database/schema.sql` – PostgreSQL database creation schema & sample data
* `/docs/architecture.md` – Technical design document & system diagrams
* `/tests/matchEngine.test.js` – Matching algorithm test cases
* `index.html` – Interactive working frontend prototype
